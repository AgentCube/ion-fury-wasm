# Ion Fury WASM

A web port of [Ion Fury](https://store.steampowered.com/app/562860/Ion_Fury/), a retro-style first-person shooter. Includes the original game and the **Aftershock** expansion.

**Play:** https://agentcube.github.io/ion-fury-wasm/

## Controls

### Keyboard & Mouse

| Action | Key / Input |
| --- | --- |
| Move | `W`, `A`, `S`, `D` |
| Look / Aim | Mouse |
| Fire | Left Mouse Button |
| Alternate Fire | Right Mouse Button |
| Jump | `Spacebar` |
| Crouch | `Ctrl` |
| Walk | `Shift` |
| Interact / Use | `E` |
| Reload | `R` |
| Switch Weapons | Number Keys |
| Pause Menu | `Escape` |

### Controller

| Action | Button |
| --- | --- |
| Move | Left Stick |
| Look / Aim | Right Stick |
| Fire | `R2 / RT` |
| Alternate Fire | `R1 / RB` |
| Jump | `L2 / LT` |
| Crouch | `L1 / LB` |
| Interact / Use | `X / A` |
| Switch Weapons | `△ / Y` |
| Pause Menu | `Options / Menu` |

### Mobile Controls

Mobile devices are supported with touchscreen controls and compatible Bluetooth controllers.

- Use the on-screen controls to move, aim, shoot, and interact.
- Tap **Controls** to customize the touchscreen layout and settings.
- Landscape orientation is recommended.

### Menu Controls

| Action | Keyboard / Mouse |
| --- | --- |
| Navigate Options | Arrow Keys / Mouse |
| Confirm / Select | `Enter` / Left Mouse Button |
| Cancel / Back | `Escape` |

## Saves

Game progress is saved locally in your browser. Use the in-game Save and Load menus to manage your saves.
